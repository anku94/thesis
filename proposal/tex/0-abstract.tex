\begin{abstract}
  The Bulk Synchronous Parallel (BSP) paradigm powers some of our most critical computational tools,
  from large-scale scientific simulations to distributed machine learning.
  As these applications scale, their efficiency has datacenter-level impacts on cost and
  time-to-discovery.
  However, the tightly synchronized nature of the BSP model creates two distinct challenges:
  significant data management hurdles from bursts of checkpointed state on the data path, and extreme
  sensitivity to execution variability on the compute path.
  While traditionally addressed by separate communities and tools, this thesis demonstrates that
  these two problems can be mapped to a common challenge of extracting actionable insight from
  real-time data streams.

  In this thesis, we first address the data path challenge.
  We present CARP, a system for streaming and adaptive data reorganization.
  Designed to operate in-situ during an application's I/O phase, CARP uses a lightweight control loop
  to monitor data distributions and continuously re-partition data as it flows to storage, enabling
  efficient analysis without costly post-processing.

  We then turn to the compute phase, investigating what is traditionally considered a load-balancing
  problem in adaptive parallel codes.
  While attempting to characterize and remedy load imbalance, we repeatedly faced the deeper
  challenge of distinguishing true workload effects from systemic variability caused by the
  underlying hardware and software stack.
  When existing performance tools failed to provide the necessary analytical leverage, we resorted to
  developing our own telemetry pipelines, which organically evolved towards a modern OLAP stack.
  This diagnostic journey led us to a core conclusion: the most difficult problem is often not
  solving the issue at hand, but first knowing what the real problem is.

  Our experiences motivated the need for a general-purpose framework for programmable, interactive,
  and real-time analytics on streaming telemetry in large clusters.
  This work culminates in ORCA, a system that synthesizes the lessons from our prior investigations.
  ORCA generalizes the core mechanism from CARP—reconstructing a global view of system state from
  hierarchical aggregations to guide better decisions—and applies it to the diagnostic challenge
  identified in our performance studies.
  Through its declarative abstractions and query-driven dataflows, ORCA provides the unified
  observability and control necessary to transform how we analyze, tune, and interact with
  large-scale computational systems.
\end{abstract}
