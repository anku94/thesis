\subsection{Anatomy of Modern
Clusters}\label{anatomy-of-modern-clusters}

\begin{itemize}
\item
  Cluster resources: nodes, memory hierarchies, accelerators (e.g.,
  GPUs).
\item
  \textbf{Networking:}

  \begin{itemize}
  \tightlist
  \item
    HPC: specialized high-speed fabrics (e.g., InfiniBand, Aries) for
    collectives, plus Ethernet control networks.
  \item
    ML clusters: backend networks for data, frontend for orchestration.
  \end{itemize}
\item
  Storage infrastructure: parallel filesystems (Lustre, GPFS, BeeGFS),
  burst buffers, SSD tiers.
\end{itemize}

\subsection{In-Situ Analytics: Community Drivers and Status
Quo}\label{in-situ-analytics-community-drivers-and-status-quo}

\begin{itemize}
\item
  Traditional ``persist-then-analyze'' model and its breakdown at scale.
\item
  Why in-situ emerged: reducing time-to-insight, bandwidth needs, and
  storage costs.
\item
  Overview of major in-situ paradigms:

  \begin{itemize}
  \tightlist
  \item
    Tightly coupled: libraries embedded in simulation.
  \item
    Loosely coupled: co-processing with staging/burst nodes.
  \item
    Overlay networks: aggregation and scalable monitoring.
  \item
    In-situ indexing: hash-based (DeltaFS), range (missing).
  \end{itemize}
\item
  Limitations of each and the context for new approaches.
\end{itemize}
